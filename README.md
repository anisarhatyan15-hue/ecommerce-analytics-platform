  Real-Time E-Commerce Analytics & Monitoring Platform

Այս նախագիծը իրական ժամանակում էլեկտրոնային խանութի տվյալների հավաքագրման, վերլուծության և համակարգի մոնիտորինգի (SRE) հարթակ է։

  Օգտագործված Տեխնոլոգիաներ
* **Backend & API:** FastAPI, Python
* **Data Processing:** Pandas
* **Storage:** SQLite (SQL)
* **Visual Dashboard:** Streamlit
* **System Monitoring:** psutil

  Ինչպե՞ս աշխատեցնել
1. Տեղադրել գրադարանները՝ `pip install -r requirements.txt`
2. Միացնել տվյալների բազան՝ `python database.py`
3. Միացնել տվյալների գեներատորը՝ `python generator.py`
4. Աշխատեցնել Dashboard-ը՝ `streamlit run dashboard.py`
